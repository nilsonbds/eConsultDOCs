## 🖥️ Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/econsultdocs.git
```

Entre na pasta:

```bash
cd econsultdocs
```

Instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run start
```

---

## 📦 Build para produção

```bash
npm run build
```

Gerar a versão estática:

```bash
npm run serve
```

## 🏗️ Arquitetura

O projeto foi desenvolvido utilizando o **Docusaurus**, permitindo a criação de documentação moderna baseada em Markdown, com geração de site estático, versionamento e estrutura otimizada para SEO.

```text
Markdown / MDX
        │
        ▼
   Docusaurus
        │
        ▼
 React Components
        │
        ▼
Static Website
```
