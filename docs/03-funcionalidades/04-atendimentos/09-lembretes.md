# Lembretes do Atendimento

A funcionalidade "Lembretes do Atendimento" no sistema eConsult é uma ferramenta estratégica e altamente eficaz para aprimorar a organização, o foco e a qualidade dos atendimentos realizados. Com ela, os profissionais podem configurar até **seis tipos diferentes de lembretes**, cada um representado por uma **cor distinta**, o que proporciona uma visualização rápida e intuitiva das informações essenciais relacionadas a cada caso.

Essa **codificação por cores** permite que os usuários identifiquem com facilidade os lembretes vinculados a um atendimento específico, facilitando a distinção entre diferentes categorias de ações, como follow-ups, pendências administrativas, exames a serem solicitados, entre outros. Dessa forma, as prioridades são evidenciadas com clareza, reduzindo a chance de esquecimentos e contribuindo para uma tomada de decisão mais ágil e assertiva.

Além disso, os lembretes funcionam como um apoio visual contínuo durante o fluxo de trabalho, permitindo que o profissional mantenha o **foco nas tarefas mais relevantes** e otimize a gestão do tempo.

Em resumo, os "Lembretes do Atendimento" representam um recurso valioso dentro do eConsult, que alia praticidade, clareza visual e gestão estratégica para elevar o padrão dos serviços prestados.

## Atribuir lembrete ao atendimento

1. Acione a opção ![Atendimento](../../../static/img/prints/atendimento/069.png) no *card* do atendimento que deseja atribuir lembrete.

    ![Atendimento](../../../static/img/prints/atendimento/064.png)

1. O sistema abre a tela "Lembretes para o Atendimento".

    ![Atendimento](../../../static/img/prints/atendimento/065.png)

1. Selecione os lembretes desejados clicando sobre as cores disponibilizadas.

    ![Atendimento](../../../static/img/prints/atendimento/066.png)

1. Após selecionar os lembretes, feche a tela. 

1. O sistema atualizará automaticamente o *card* do atendimento, exibindo as cores dos lembretes associados.

    ![Atendimento](../../../static/img/prints/atendimento/067.png)

:::tip
Para desvincular todos os lembretes de um atendimento, basta acionar a opção "Sem lembrete" na tela "Lembretes para atendimento".

![Atendimento](../../../static/img/prints/atendimento/068.png)
:::
