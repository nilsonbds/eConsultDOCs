# Sobre Conta

Manter os dados cadastrais atualizados é essencial para garantir a precisão das informações e a eficiência no atendimento.

O Painel Conta envolve a atualização de diversas informações, como dados gerais da conta, assinaturas, endereços, foto de perfil, logotipo e assistentes.

Para acessar o **Painel Conta**, acione a opção ![Conta](../../../static/img/prints/buttons/btn_ola-sigmond.png) no topo da tela e em seguida clique na imagem da conta ![Conta](../../../static/img/prints/buttons/btn_foto-perfil-sigmond.png). O sistema abrirá o painel conforme mostrado abaixo:

![Painel Conta](../../../static/img/prints/00_visao-conta-001.png)

## Abas do Painel Conta

| Ícone | Aba |
|---|---|
| ![Painel Conta](../../../static/img/prints/00_visao-conta-002.png) | **Dados Gerais:** Permite o cadastro de seus dados gerais. |
| ![Painel Conta](../../../static/img/prints/00_visao-conta-003.png) | **Assinatura:** Onde você faz a gestão das suas assinaturas do eConsult. |
| ![Painel Conta](../../../static/img/prints/00_visao-conta-004.png) | **Endereços:** Onde você cadastra o seu endereço principal e demais endereços (se for o caso). |
| ![Painel Conta](../../../static/img/prints/00_visao-conta-005.png) | **Foto Perfil:** Permite o cadastro da sua foto de perfil. |
| ![Painel Conta](../../../static/img/prints/00_visao-conta-006.png) | **Logotipo:** Permite o cadastro do seu logotipo. |
| ![Painel Conta](../../../static/img/prints/00_visao-conta-007.png) | **Assistentes:** Permite o cadastro de seus assistentes. |
