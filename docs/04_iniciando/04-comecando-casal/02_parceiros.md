# Cadastre os parceiros do casal

👥 Cadastre os parceiros que fazem parte do casal antes de cadastrar o casal no eConsult.

> 💡 Leva menos de 1 minuto para cadastrar cada membro.

O primeiro passo para iniciar um atendimento de casal no eConsult é simples:

👉 comece cadastrando individualmente cada parceiro que fará parte do casal.

## 👤 Como cadastrar um membro do casal

Cadastrar um membro é rápido e direto.

### Passo a passo:

1. Acesse o painel **Pessoas Atendidas**

    ![Pessoas atendidas](../../../static/img/prints/clientegrupo/clientegrupo-001.png)

2. Clique em **Incluir novo paciente, casal, família ou grupo** ![Incluir novo paciente, casal, família ou grupo](../../../static/img/prints/buttons/btn_add.png)

3. Preencha os dados principais:

   - **Nome** (obrigatório)
   - **Tipo de atendimento**: membro de casal
   - **Outras informações**: opcionais neste primeiro momento

    ![Pessoa Atendida](../../../static/img/prints/clientegrupo/clientegrupo-007.png)

4. Salve o cadastro ![Salvar cadastro](../../../static/img/prints/buttons/btn_add.png)

👉 Pronto. Agora este membro poderá ser vinculado ao cadastro do casal.

🚀 Experimente cadastrar os dois parceiros antes de continuar.

---

## 💡 Dica importante

Você não precisa preencher tudo agora.

O mais importante é:

✔ cadastrar os parceiros do casal  
✔ deixar os membros disponíveis para vínculo no cadastro do casal  
✔ complementar as informações depois, conforme a necessidade  

---

## 🎯 Por que começar por aqui?

Porque o atendimento de casal no eConsult parte de uma estrutura relacional:

- membros → casal → atendimentos → registros → evolução

Ao cadastrar os membros primeiro, você prepara a base para:

✔ agenda  
✔ prontuário do casal  
✔ registros clínicos  
✔ marcadores clínicos  
✔ acompanhamento longitudinal
