# Restaurar Dados de Conta

A tela de restauração de conta do sistema eConsult permite que o usuário recupere dados de sua conta utilizando o arquivo de backup gerado anteriormente (arquivo eConsultData.json).

Para acessar o painel **Restaurar Dados de Conta**, acione a opção correspondente ![Conta](../../../static/img/prints/buttons/restaurar_dados_da_conta.png) na aba Dados Gerais.

    ![Conta](../../../static/img/prints/00_visao-conta-002.png)

### Orientações importantes

- **Verificação do arquivo:** certifique-se de que o arquivo selecionado é realmente o backup correto da conta que deseja restaurar.

- **Validação automática:** o sistema verificará se o arquivo pertence ao profissional logado.

- **Backup adicional:** recomenda-se criar um novo backup antes de realizar a restauração, como medida de segurança.

:::warning
A restauração sobrescreve todos os dados atuais da conta, substituindo-os pelos dados do arquivo importado.
:::

### Como restaurar uma conta

1. Clique em Escolher Arquivo e selecione o arquivo eConsultData.json no seu dispositivo.

1. Apenas arquivos com esse nome e formato serão aceitos.

1. Caso selecione um arquivo incorreto, o sistema exibirá uma mensagem de erro.

1. Preencha os campos obrigatórios:

    - Email: insira o mesmo endereço de e-mail cadastrado no sistema.

    - Senha: digite sua senha de acesso.

1. Clique no botão “Restaurar Conta”.

:::note Observações

O processo de restauração pode levar alguns segundos, dependendo do tamanho do arquivo.

Somente o titular da conta, com e-mail e senha corretos, pode realizar a restauração.

Após a conclusão, todos os dados da conta serão substituídos pelas informações contidas no arquivo importado.

:::
