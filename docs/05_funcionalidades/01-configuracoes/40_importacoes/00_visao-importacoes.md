# Sobre Configurações para Importações

O grupo **Importações** reúne os recursos para trazer dados de planilhas ou de outros sistemas para o eConsult, facilitando a migração e evitando a necessidade de cadastrar novamente as informações de forma manual.

As importações são realizadas em etapas. Primeiro, o eConsult lê e analisa o arquivo enviado, identifica as informações disponíveis e organiza os dados de acordo com a estrutura utilizada pelo sistema. Antes de qualquer cadastro ser realizado, é apresentada uma **prévia dos dados identificados**, permitindo que você confira o resultado e escolha quais registros deseja importar.

Esse processo permite trabalhar inclusive com planilhas que possuem nomes de colunas e estruturas diferentes das utilizadas pelo eConsult.

### Importação de Pessoas Atendidas

Permite importar cadastros de pessoas atendidas a partir de arquivos **Excel ou CSV**.

Durante o processamento, o eConsult procura identificar informações como **nome, CPF, data de nascimento, e-mail, telefone, celular e endereços**.

Quando uma mesma pessoa aparece em mais de uma linha da planilha, o eConsult pode identificar que os registros pertencem à mesma pessoa e consolidar as informações. Isso é especialmente útil quando a planilha possui **mais de um endereço para a mesma pessoa atendida**.

Após a análise, os cadastros identificados são apresentados para revisão. Você poderá:

* conferir as pessoas identificadas;
* visualizar os dados que serão cadastrados;
* consultar os endereços encontrados para cada pessoa;
* selecionar ou desmarcar individualmente os registros;
* escolher exatamente quais pessoas serão importadas.

Somente os registros **selecionados por você** serão enviados para a importação.

### Antes de importar

Embora o eConsult analise e organize automaticamente as informações encontradas, recomendamos revisar os dados apresentados antes de confirmar a importação.

Informações ausentes na planilha não são criadas automaticamente. Dependendo da estrutura e da qualidade dos dados de origem, alguns campos podem não ser identificados ou podem permanecer sem preenchimento.

A importação tem como objetivo facilitar a migração de dados, mantendo você no controle sobre quais informações serão efetivamente cadastradas no eConsult.
