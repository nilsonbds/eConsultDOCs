# Daily (Teleatendimento)

O **eConsult** conta com **integração nativa com o Daily (daily.co)**, uma plataforma moderna e segura de **teleatendimento por vídeo**, pensada para facilitar consultas remotas com seus pacientes.

Essa funcionalidade permite que você realize atendimentos diretamente pela plataforma, com **qualidade de áudio e vídeo**, sem necessidade de instalar programas adicionais.

A integração é simples, rápida e não exige conhecimentos técnicos avançados.

---

## Vantagens do Teleatendimento com Daily

Com essa integração, você pode:

- **Realizar atendimentos por vídeo** com apenas um clique, direto do eConsult
- Enviar **links de acesso seguros** para pacientes automaticamente
- Garantir **criptografia ponta a ponta**, protegendo os dados sensíveis
- Utilizar em qualquer dispositivo (computador, tablet ou celular)
- **Evitar custos adicionais**, pois o Daily tem planos flexíveis e acessíveis

---

## Como funciona a integração

1. **No agendamento de atendimento**, você verá o botão **Teleatendimento**.

2. Ao clicar, o sistema gera automaticamente uma **sala de atendimento segura**, com link exclusivo.

3. O link pode ser:
   - Copiado para envio manual  
   - Ou enviado diretamente ao paciente via e-mail

4. O paciente acessa a sala no navegador, **sem necessidade de cadastro ou instalação de app**.

---

## Configurar sua Conta no Daily

Para ativar o teleatendimento via Daily no eConsult, siga estes passos:

### 1. Crie uma conta no Daily

- Acesse: [https://www.daily.co](https://www.daily.co)
- Clique em **“Sign Up”** para criar sua conta

### 2. Copie sua API Key

- Após criar sua conta, acesse o painel: [https://dashboard.daily.co/developers](https://dashboard.daily.co/developers)
- Copie sua chave para usar no eConsult

### 3. Configure no eConsult

- No eConsult, vá até o painel **Configurações**
- Acesse **Integrações / Daily (Teleatendimento)**
- Cole a **chave de API** copiada anteriormente
- Clique em **Salvar**

**Pronto!** A partir de agora, você poderá iniciar videochamadas diretamente no eConsult.

---

## Dicas de Uso

- Utilize o **Google Chrome ou Safari** para melhor compatibilidade
- Fones de ouvido com microfone ajudam a melhorar a qualidade do áudio
- Certifique-se de que seu navegador tenha permissão para acessar **câmera e microfone**

---

## Planos e Limites do Daily

O Daily possui um plano gratuito com:

- **Até 10.000 minutos grátis todos os meses**

Caso precise de mais tempo, é possível contratar planos pagos diretamente na plataforma [Daily.co](https://www.daily.co/pricing).
