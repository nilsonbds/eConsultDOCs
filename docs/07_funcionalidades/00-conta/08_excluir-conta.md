# Excluir Conta

A tela de exclusão de conta do sistema eConsult é utilizada quando você deseja remover permanentemente sua conta e todos os dados associados.

:::warning
- A exclusão da conta é permanente e irreversível.

- Todos os dados vinculados serão removidos, incluindo:
    - Informações pessoais do usuário.
    - Registros de clientes.
    - Histórico de sessões e pagamentos.
    - Uma vez confirmada a exclusão, não será possível recuperar os dados.
:::

## Exportar Dados

Antes de fazer a exclusão, o sistema oferece a opção de exportar os dados.

O backup inclui todas as informações da conta em um arquivo seguro.

Para exportar, clique no botão “Exportar Dados”.

Recomenda-se realizar esta operação antes de excluir a conta, garantindo que você mantenha uma cópia para consulta futura.

### Confirmando a Exclusão da Conta

Para confirmar a exclusão definitiva da conta:

1. Preencha o campo Email com o endereço de e-mail cadastrado.

1. Digite sua Senha corretamente.

1. Clique no botão vermelho “Confirmar Exclusão”.

:::warning
- Somente o titular da conta, com acesso ao e-mail e senha, pode realizar a exclusão.

- Após a confirmação, todos os dados serão removidos do sistema.

- Caso tenha dúvidas, recomenda-se exportar os dados primeiro e entrar em contato com o suporte antes de prosseguir.
:::
